# Clínica Podológica Gros · propuesta web

Demo comercial **no oficial** para Clínica Podológica Gros (Nora Hernández / Iñaki Cid). Es una página estática sin formularios, analítica ni almacenamiento de datos. Lleva `noindex, nofollow` hasta que la clínica autorice una web oficial.

## Filtro comercial

**Sí merece una demo.** La clínica tiene presencia en Google Maps y numerosos directorios, pero no se encontró una web propia activa. El dominio histórico `clinicapodologicagros.com` aparece en [TodosBiz](https://www.todosbiz.es/cl%C3%ADnica-podologica-gros-nora-hern%C3%A1ndez-943-32-69-71) y [Infopiniones](https://www.infopiniones.es/salud/clinica-podologica-gros-nora-hernandez/); el 2 de octubre de 2026 no resolvía por DNS, con o sin `www`. No se encontró un sitio nuevo asociado de forma fiable a esta clínica. Por ello no había una web actual que auditar en móvil. La oportunidad es concentrar en una pantalla ligera y legible el nombre, la dirección, el número de teléfono, los servicios que pueden mencionarse con cuidado y una llamada inmediata. Una web real debería confirmar primero el catálogo de servicios y los detalles de los profesionales.

## Concepto y recursos

**Clínica de barrio contemporánea.** Blanco hueso, petróleo apagado, líneas de recorrido y señalética de Usandizaga 20. La composición toma la idea de caminar y llegar, sin dibujos de pies ni promesas sanitarias. Las secciones son: portada con llamada, identidad y datos, personas, podología contrastada, pedir cita, opiniones, ubicación, dudas prácticas y contacto final.

`assets/clinica-conceptual.webp` fue generado con la herramienta integrada `image_gen` y optimizado a WebP (aprox. 148 KB). Prompt: interior arquitectónico ficticio de una pequeña clínica de barrio, luz natural, suelo claro y banco azul petróleo, sin personas, pies, instrumental, rótulos ni símbolos médicos. **No representa el establecimiento real** y la página lo identifica. El favicon es un SVG original creado para la demo. No se descargaron fotos del negocio ni de directorios.

## QA

Navegador real a 320, 375, 390, 430, 768, 1024 y 1280 px: sin scroll horizontal ni imágenes rotas. Comprobados apertura y cierre del menú móvil, navegación a cita, FAQ, anclajes internos, enlace telefónico, URL de Maps, consola sin errores, ausencia de formularios, identificación de demo y `noindex, nofollow`. `script.js` pasa `node --check` y los archivos de texto pasan Prettier. La imagen principal ocupa aproximadamente 148 KB; no hay librerías de interfaz ni servicios externos cargados por la página.

## Ejecutar y publicar

Desde esta carpeta:

```powershell
python -m http.server 8000
```

Abrir `http://localhost:8000/`. El workflow `.github/workflows/pages.yml` despliega desde `main` con GitHub Actions. Fuente de Pages: **GitHub Actions**. La URL del repositorio remoto es `https://github.com/Urtxe/podologica-gros-demo` y la de Pages `https://urtxe.github.io/podologica-gros-demo/`.

Antes de convertirla en web oficial: confirmar con Nora e Iñaki el papel de cada uno, servicios vigentes, horarios, sistema de citas, fotografías autorizadas y textos sanitarios. Solo entonces retirar `noindex, nofollow` y la indicación de propuesta no oficial.
